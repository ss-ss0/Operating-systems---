Question 1 • 3 partsOriginal

Question 1

  1. What is an operating system do? Illustrate the Layered approach for operating system structure.
  2. What is the purpose of system call? Explain briefly and illustrate by example how a system call is implemented. In Unix systems, what system calls have to be executed in order to start a new process?
  3. Distinguish between shared memory and message passing models of Inter Process Communication.
📌 ركّز: OS definition, Layered Approach, System Calls, fork/exec/wait, Shared Memory vs Message Passing.
Question 2 • 3 partsOriginal

Question 2

  1. Sketch and illustrate a diagram of process state transitions.
  2. Explain briefly the race condition problem.
  3. Given processes P1–P5 with Burst Time, Arrival Time and Priority, draw four Gantt charts using FCFS, non-preemptive SJF, preemptive Priority and Round Robin (quantum = 8), calculate the average waiting time for each algorithm, then comment on the results.
📌 المسألة الثقيلة: Gantt Chart + Average Waiting Time عبر أربع Scheduling Algorithms.

Final 2021/2022 • Q1Original

Operating System + Processes + Scheduling

  • What is meant by an operating system? Illustrate the structure of a process in memory and sketch process state transitions.
  • Explain how a system call is implemented; in Unix, what calls are executed to start a new process?
  • Draw Gantt charts for FCFS, non-preemptive SJF, preemptive Priority and RR (quantum = 16), then calculate average waiting time.
Final 2021/2022 • Q2Original

Deadlock + Synchronization

  • Explain deadlock avoidance and determine whether the system is in a safe state using Banker's Algorithm, step-by-step.
  • Explain the race condition problem and write wait() and signal() semaphore operations; describe the bounded-buffer solution.
Final 2021/2022 • Q3Original

Memory Management

  • Allocate memory requests using First-Fit, Next-Fit, Best-Fit and Worst-Fit and decide which makes the most efficient use of memory.
  • Paging: draw logical/physical memory and translate logical addresses using a page table.
Final 2021/2022 • Q4Original

Virtual Memory + Disk Scheduling

  • Explain benefits of virtual memory, process a page fault, and compute Effective Access Time.
  • Explain seek time and schedule disk requests using FCFS, SSTF, SCAN and C-SCAN.
Final 2022/2023 • repeated structureOriginal

What repeated in the next final?

The 2022/2023 final repeats the same major structure: OS/processes + four scheduling algorithms, Banker's/deadlock avoidance, race condition/semaphores, memory allocation + paging, virtual memory/page fault/EAT, and disk scheduling.
